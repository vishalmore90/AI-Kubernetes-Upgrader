Privacy Policy

Our privacy commitments for infrastructure assessments and cluster snapshot processing.

1. Zero Credential Collection

AI-Kubernetes-Upgrader does not request, collect, or store Kubernetes credentials, kubeconfig secrets, cloud access tokens, or private certificates. In public demo mode, all outbound cluster communication is disabled by default.

2. In-Memory Snapshot Processing

Cluster snapshots uploaded for analysis are processed strictly in ephemeral server memory. Any temporary files created during JSON deserialization are unlinked and destroyed immediately upon analysis completion or failure.

3. No Tracking or User Profiling

We do not use tracking cookies, commercial analytics scripts, or third-party behavioral profiling. Client IP addresses are utilized exclusively in volatile memory for rate-limiting protection against service abuse.

4. Data Retention

No cluster assessment data is persisted to a database or disk storage. When an assessment session ends or the server instance spins down, all in-memory evaluation records are wiped.

Effective Date: October 2026. For questions or security inquiries, visit the project repository on GitHub.
